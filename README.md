# chatbothelpdesk
WHAT IS THIS?
<br>
A chatbot which acts as your college helpdesk and helps you with your queries.
This will help you anywhere anytime unlike those conventional helpdesks.
<br>
Deals with student inquiries and provide instant support for campus-related questions with 24/7 assistance to students.
<br>
FEATURES
1. Answers FAQs about admissions, fee structures, and course details.
2. Ensures students get help even after office hours.
3. Simple to use.
4. Takes both text and image queries.
5. Model used: "nvidia/nemotron-nano-12b-v2-vl"
6. Retains the previous chat history to answer your future questions.
7. Backend : FASTAPI (A modern, high-performance web framework for building APIs with Python.)
8. Frontend : HTML & CSS
9. AI Orchestration : Openrouter API
<br>
LEARNINGS
1. Application of multimodal AI system.
2. Integrating LLM & VLM.
3. API Interface.
4. Deployment of AI-powered web applications.
